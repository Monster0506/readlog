https://newsletter.kentbeck.com/p/composable-tests i normally like Kent Beck's opinions, but I'm not sure I agree with this one. I think looking at a failing test should provide all assertations up to that point. e.g.,  ensuring that the state is as expected to programmers who might not have written that test in the first place. Yes, it does make for cleaner code, but I think there is benefit in tracing the things that must be assumed to be true without having to find a test that asserts them any earlier.
